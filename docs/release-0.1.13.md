# dytes 0.1.13 版本更新

## 依赖与插件安装

- **循环依赖不再中止更新**：拓扑排序遇到回边（如
  `system/chatllm -> webs/chat_ui -> system/chatllm`）时跳过该边并输出警告，
  其余依赖继续安装。
- **已安装依赖去重**：非根依赖如果已安装且版本不低于线上版本，不再展开其子依赖；
  未安装或版本落后的包仍安装线上最新版本。
- **插件安装复用同一套依赖逻辑**：`dytes install plugin` /
  `dytes install design-soft` 会先读取插件清单，安装其声明依赖，再安装插件本身。
  依赖的跳过 / 升级判断与 `dytes update` 一致。

## 兼容性

- 已有锁文件格式不变；
- 环上的包仍会各安装一次，不会因为互依赖而重复下载或无限递归；
- 安装完成后仍按原逻辑执行依赖的 init 脚本。
